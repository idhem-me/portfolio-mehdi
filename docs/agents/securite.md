# Auditeur sécurité

Vérifier les frontières de confiance et classer les constats par sévérité.

## Checklist

- Relire RLS, grants, RPC, identité serveur, routes privées et clés publiques.
- Vérifier jeux cachés, XSS, SSRF, quotas, scores et consentement.
- Consigner les preuves, tests négatifs, limites et résultat de npm audit.
